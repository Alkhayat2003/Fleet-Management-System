# نظام إدارة الأسطول - Frontend

## نظرة عامة

تطبيق Next.js متكامل لنظام إدارة الأسطول مع واجهة مستخدم حديثة وجذابة، مصمم خصيصاً للغة العربية مع دعم كامل لـ RTL.

## المميزات

### 🎨 نظام ألوان متكامل
- **ألوان أساسية**: أزرق احترافي (#2563eb) مع تدرجات متناسقة
- **ألوان الحالة**: أخضر للنجاح، برتقالي للتحذير، أحمر للخطأ، أزرق فاتح للمعلومات
- **ألوان محايدة**: تدرج رمادي من الفاتح إلى الداكن
- **متدرجات جذابة**: 5 متدرجات مختلفة للبطاقات الإحصائية
- **ظلال متناسقة**: نظام ظلال موحد لجميع العناصر

### 🎯 تصميم متجاوب
- تصميم متجاوب يعمل على جميع الأجهزة
- دعم كامل للغة العربية واتجاه RTL
- واجهة مستخدم حديثة مع تأثيرات بصرية جذابة

### 🗺️ خريطة تفاعلية
- خريطة Leaflet مع أيقونات مخصصة للمركبات
- تتبع مباشر للمركبات في الوقت الحقيقي
- إمكانية التبديل بين الخريطة العادية والصور الجوية

### 📊 لوحة تحكم شاملة
- 5 بطاقات إحصائية مع متدرجات ملونة
- عرض المركبات النشطة، في الصيانة، الرحلات النشطة والمكتملة
- خريطة تفاعلية تستغل المساحة الكاملة

### 🔐 نظام مصادقة آمن
- تسجيل دخول آمن باستخدام JWT
- إدارة حالة المستخدم مع React Context
- واجهة تسجيل دخول جذابة مع تأثيرات بصرية

## نظام الألوان

```typescript
primary: {
  main: '#2563eb',    // الأزرق الرئيسي

  dark: '#1d4ed8',    // الأزرق الداكن
  contrastText: '#ffffff'

```

```typescript

}
```

## التثبيت والتشغيل

### المتطلبات
- Node.js 18+ 
- npm أو yarn

### التثبيت
```bash
# تثبيت التبعيات
npm install

# تشغيل التطبيق في وضع التطوير
npm run dev

# بناء التطبيق للإنتاج
npm run build

# تشغيل التطبيق المبنى
npm start
```

## المكونات الرئيسية

### Header
- رأس ثابت مع متدرج أزرق جذاب
- أيقونة واسم التطبيق في المنتصف
- ظلال وتأثيرات بصرية محسنة

### Sidebar
- شريط جانبي قابل للطي على اليمين
- متدرج بنفسجي-أزرق جذاب
- رسالة ترحيب مع اسم المستخدم
- روابط مع أيقونات وتأثيرات حركية

### Dashboard
- 5 بطاقات إحصائية مع متدرجات مختلفة
- خريطة تفاعلية تستغل المساحة الكاملة
- تأثيرات حركية عند التمرير
- تصميم متجاوب ومحسن

### MapComponent
- خريطة Leaflet مع أيقونات مخصصة
- ألوان مختلفة حسب حالة المركبة
- popup تفاعلي مع معلومات مفصلة
- إمكانية التبديل بين أنواع الخرائط
